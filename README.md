# 선민종합관리 민원 처리부

관리사무소 민원을 **접수 → 지시 → 보고 → 회신** 순서로 처리하는 웹 앱입니다.
설치나 서버 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다.

## 사용 흐름

1. **접수 (관리소장)**: `+ 민원 접수`에서 민원인 이름, 연락처, 동·호수, 분류, 긴급 여부, 내용을 입력합니다.
2. **지시 (관리소장)**: 담당 직원, 처리 기한, 지시 사항을 정해 보냅니다. 처리 중에는 `담당 변경 · 추가 지시`로 담당을 바꾸거나 지시를 더 보낼 수 있습니다.
3. **보고 (직원)**: 상단 `직원` 화면에서 자기 이름을 고르면 자기에게 온 지시만 보입니다. 여기서 `진행 보고`나 `완료 보고`를 올립니다.
4. **회신 (관리소장)**: 완료 보고가 오면 상단에 **회신 대기 N건**이 표시됩니다.
   - 민원인에게 보낼 안내 문구가 자동으로 만들어집니다. 고친 뒤 `문구 복사`로 문자·카톡에 붙여 보내거나, 휴대폰에서는 `문자 앱 열기`로 바로 보냅니다.
   - 보낸 방법(문자, 카톡, 전화, 방문)을 고르고 `회신완료로 기록`하면 **회신완료**로 바뀝니다.
   - 처리 중에도 `민원인에게 중간 안내`를 보낼 수 있고, 보고가 부족하면 `재작업 지시`로 다시 돌려보냅니다.

## 로고

- 저장소 루트에 `logo.png` 파일을 올리면 상단과 브라우저 탭에 선민종합관리 로고가 표시됩니다.
- 또는 앱의 `직원·설정 → 로고 이미지 올리기`로 그 기기에만 로고를 넣을 수 있습니다.
- 로고가 없으면 초록색 "선민" 글자 마크가 대신 보입니다.

## 데이터 저장

- 민원 기록은 **사용하는 기기의 브라우저(localStorage)** 에 저장됩니다. 같은 PC에서 관리소장 창과 직원 창을 따로 열어도 서로 반영됩니다.
- 다른 기기와는 자동으로 공유되지 않습니다. `직원·설정 → 백업 파일 받기 / 백업 불러오기`로 옮기거나 정기적으로 백업하세요.
- 민원인 이름·연락처는 개인정보입니다(개인정보 보호법 제29조 안전조치의무). 공용 PC에서는 브라우저 계정을 분리해 쓰세요.
