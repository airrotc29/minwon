# 선민종합관리 민원 처리부

관리사무소 민원을 **접수 → 지시 → 보고 → 회신** 순서로 처리하는 웹 앱입니다.
설치나 서버 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다.

## 사용 흐름

1. **접수 (관리소장 또는 직원)**: `+ 민원 접수`에서 동·호수, 분류, 긴급 여부, 내용을 입력합니다.
   - 직원이 접수하면 접수자 이름이 남고, 소장님 화면 **지시 대기**로 넘어갑니다.
   - 직원이 `내가 바로 처리`에 체크하면 소장 지시 없이 자기 담당으로 바로 처리하고 보고를 올립니다.
2. **지시 (관리소장)**: 담당 직원, 처리 기한, 지시 사항을 정해 보냅니다. 처리 중에는 `담당 변경 · 추가 지시`로 담당을 바꾸거나 지시를 더 보낼 수 있습니다.
3. **보고 (직원)**: 상단 `직원` 화면에서 자기 이름을 고르면 자기에게 온 지시만 보입니다. 여기서 `진행 보고`나 `완료 보고`를 올립니다.
4. **회신 (관리소장)**: 완료 보고가 오면 상단에 **회신 대기 N건**이 표시됩니다.
   - 민원인에게 보낼 안내 문구가 자동으로 만들어집니다. 휴대폰에서 노란 **카톡으로 보내기**를 누르면 공유창이 뜨고, 카카오톡에서 받을 방을 고르면 문구와 완료 사진이 함께 갑니다(문구는 복사도 되어 있어 글이 빠지면 붙여넣기). PC에서는 문구가 복사되니 PC 카톡에 붙여넣으면 됩니다.
   - 고친 뒤 `문구 복사`로 붙여 보내거나 인터폰·방문으로 알립니다.
   - 알린 방법(인터폰, 방문, 전화, 문자, 카톡, 안내문 부착)을 고르고 `회신완료로 기록`하면 **회신완료**로 바뀝니다.
   - 처리 중에도 `민원인에게 중간 안내`를 보낼 수 있고, 보고가 부족하면 `재작업 지시`로 다시 돌려보냅니다.

## 사진

- 접수할 때와 직원이 진행·완료 보고를 올릴 때 **＋ 사진**으로 사진을 붙입니다(한 번에 6장까지). 휴대폰에서는 바로 촬영하거나 앨범에서 고를 수 있습니다.
- 휴대폰 사진은 올리기 전에 자동으로 줄입니다(긴 변 1280px, 장당 약 150KB).
- 처리 내역에 작은 사진으로 보이고, 누르면 크게 보거나 저장할 수 있습니다.
- GitHub에 연결돼 있으면 비공개 저장소 `photos/` 폴더에, 아니면 그 기기에 저장됩니다. 연결 전에 찍은 사진은 처음 연결할 때 함께 올라갑니다.
- 백업 파일(json)에는 사진이 들어가지 않습니다. 사진은 GitHub 저장소에 남습니다.

### 사진이 많이 쌓일 때: 연도별 사진 저장소
GitHub 저장소 하나는 1GB 이하가 권장이고, 넘더라도 5GB 미만으로 쓰는 것이 좋습니다. Git은 지운 파일도 기록에 남기므로 사진을 지워도 용량은 줄지 않습니다. 그래서 사진은 **연도별로 저장소를 나눕니다**.

1. 새 비공개 저장소를 만듭니다. 예: `minwon-photos-2026`
2. 토큰 설정(Fine-grained token → Edit → Repository access)에 그 저장소를 추가합니다. Contents 읽기·쓰기 권한이 있어야 합니다.
3. 앱 `직원·설정 → 사진 저장소`에 `airrotc29/minwon-photos-2026`을 넣고 **사진 저장소 바꾸기**를 누릅니다.

- 바꾼 뒤 새 사진은 새 저장소에 저장되고, 예전 사진은 원래 저장소에서 그대로 불러옵니다.
- 설정 화면에서 사진 저장소 사용량을 볼 수 있고, 4GB를 넘으면 소장님 화면 위쪽에 안내가 뜹니다.
- 예상량: 하루 민원 10건 × 사진 3장이면 1년에 약 1.6GB입니다.

## 로고

- 저장소 루트에 `logo.png` 파일을 올리면 상단과 브라우저 탭에 선민종합관리 로고가 표시됩니다.
- 또는 앱의 `직원·설정 → 로고 이미지 올리기`로 그 기기에만 로고를 넣을 수 있습니다.
- 로고가 없으면 초록색 "선민" 글자 마크가 대신 보입니다.

## 데이터 저장

### 기본: 이 기기에만 저장
설정 없이 쓰면 민원 기록은 그 기기의 브라우저에만 저장됩니다.

### 여러 기기 같이 쓰기: GitHub 비공개 저장소
별도 서버 없이 GitHub만으로 소장님 PC와 직원 휴대폰이 같은 기록을 씁니다.
데이터는 **비공개 저장소의 `data.json`** 하나에 저장되고, 변경할 때마다 커밋이 남아 처리 이력이 자동으로 쌓입니다.
각 기기는 20초마다(또는 상단 `동기화됨` 표시를 누를 때) 새 내용을 받아옵니다.

1. **비공개 저장소 만들기**: GitHub 오른쪽 위 `+` → New repository → 이름 `minwon-data`, 반드시 **Private** 선택 → Create.
   (세대별 민원 내용이 들어가므로 공개 저장소에 두면 안 됩니다. 이 앱 저장소 `minwon`은 공개라서 데이터용으로 쓰지 않습니다.)
2. **토큰 만들기**: GitHub 프로필 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: **Only select repositories** → `minwon-data` 하나만
   - Permissions → Repository permissions → **Contents: Read and write**
   - 만료일은 1년 정도로 두고, 만료되면 새로 만들어 다시 연결합니다.
3. 앱에서 `직원·설정 → 여러 기기 같이 쓰기`에 `airrotc29/minwon-data`와 토큰을 넣고 **연결**.
   이 기기에 있던 기록은 처음 연결할 때 서버로 올릴 수 있습니다.
4. 같은 화면의 **직원용 연결 링크 복사**로 링크를 만들어 직원에게 보내면, 직원은 링크를 한 번 열기만 하면 연결됩니다.
   링크에는 토큰이 들어 있으니 단체방이 아니라 개별로 보내고, 직원이 퇴사하면 토큰을 새로 만들어 다시 연결하세요.

참고
- 토큰은 각 기기 브라우저에만 저장되고, 앱 저장소(공개)에는 올라가지 않습니다.
- 두 기기가 동시에 저장하면 앱이 최신 내용을 다시 받아 자동으로 합칩니다.
- `직원·설정 → 백업 파일 받기`도 정기적으로 해 두세요.
- 민원인 이름·연락처는 받지 않고 동·호수만 기록합니다. 그래도 동·호수와 민원 내용으로 세대를 알아볼 수 있으니 토큰을 아무에게나 주지 마세요.

## 웹으로 열기 (GitHub Pages)

저장소 `Settings → Pages`에서 Branch를 `main` / `(root)`로 지정하면
`https://airrotc29.github.io/minwon/` 주소로 휴대폰에서도 열 수 있습니다.
